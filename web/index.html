Build the offline game

For Android, from your own files. Everything runs in this browser; your files are never uploaded. There is no iPhone or iPad build.

[00 Prepare the runtime]

The launcher is the 25 MB app around your game APK. Choose where it comes from. In mainland China the GitHub proxy is picked on the first visit; anywhere else the site is used directly.

[01 Your files]

GAME The original 3.7.1 ARM64 game APK (JP or global). NOT CHOSEN
MASTER DATA The original master data, 20240404193219.bin.e. NOT CHOSEN

[02 Build]

ADVANCED :: MOD MENU

The optional memory menu (damage and defense multipliers, no skill cooldown, God mode, forced hit, BigHunt cap lift) is added by pointing the game's launcher at a prebuilt class that starts the menu and then the game.

Experimental: the first launch asks to allow drawing over other apps, and a menu that fails to start leaves the game untouched.

ADVANCED :: SKIP THE FILE CHECK

The build checks that your APK is the original 3.7.1 release and that the master data is the untouched 20240404193219.bin.e, because the patch offsets were read from those files. A split APK exported from an installed app has the same library and metadata, so it can still build, but a different game version will not.

EXPERIMENTAL :: PORT OFFSET

The game talks to its server on this device through ports 8003, 8080 and 3000. If another app already uses one of them, the launcher tells you. An offset moves all three. For example, 30000 gives 38003, 38080 and 33000. Leave it at 0 unless you need it, and use the same offset for updates.

        Download
        
The APK is signed and ready to install. Every APK built on this page is signed
          with the same public Bunker key, so a newer build installs over an older one and keeps your saves.
          Download the key (bunker-key.p12, password
          lunar-jp, alias nier) to sign your own builds the same way. The key is public, so anyone's build can install
          over yours. To prevent this, sign with a key of your own instead.

        
The same APK runs on a Windows PC with an Intel or AMD processor, in Google's
          Android Emulator. Download Bunker.exe from the
          latest release and put it in one folder with the APK,
          named bunker.apk, and resource_dump_android.7z. Turn on Windows Hypervisor Platform
          in Windows features, then double-click Bunker.exe. The first start downloads about 2.3 GB from
          Google and copies the game files in. Open the launcher with Ctrl+B and move with WASD. See
          Play on Windows.
